🚀 MarketHub: The Future of E-Commerce
MarketHub is a modern, full-stack ordering platform built with Django, featuring a cutting-edge Glassmorphic UI. This project bridges the gap between vendors and customers with a focus on speed, aesthetic clarity, and a "Marketplace-first" user experience.

✨ Key Features
👤 Three Distinct User Roles
Customer: A personalized "Command Center" dashboard with integrated search, product discovery, and order history.

Vendor: A dedicated business portal to manage inventory, upload high-quality product images, and track sales.

Admin: Full oversight of the MarketHub ecosystem.

🎨 Futuristic UI/UX
Glassmorphism Aesthetic: Soft blurs, translucent layers, and vibrant gradients.

Responsive Search: Action-oriented product discovery built directly into the main dashboard.

Modern Auth: Clean, symmetric login and signup flows using email-based authentication.

🛠️ Tech Stack
Backend: Python 3.12+ / Django 6.0.

Frontend: Bootstrap 5, Inter Typography, and Custom CSS.

Image Processing: Pillow (for high-fidelity product uploads).

Database: SQLite (Development phase).

🚀 Getting Started
1. Installation
Clone the repository and install the necessary dependencies:

Bash
pip install -r requirements.txt
# Ensure Pillow is installed for product images!
pip install Pillow
2. Database Setup
If you want to start with a fresh database, delete the existing db.sqlite3 file and run the migrations:

Bash
python manage.py migrate
3. Run the Server
Bash
python manage.py runserver
